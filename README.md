# Online-Quiz-App

A modern and user-friendly **Online Quiz Application** built with **Python Flask** and **SQLAlchemy**.

This project allows users to register and log in, manage students, add quiz questions, take quizzes, and view their results. It uses **SQLite** as the database and **Jinja2 templates** for dynamic web pages.

## Features

- User Registration & Login
- Student Management
-  Add Students
- Delete Students
- Add Quiz Questions
- Take Online Quiz
- Automatic Quiz Score Calculation
- Result Page
- SQLite Database
- Modern Responsive UI

## Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML5
- CSS3
- Jinja2
- Git & GitHub
